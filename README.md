
# ①課題名
表情判定にらめっこアプリ

## ②課題内容（どんな作品か）
- カメラで顔を認識し、表情（口の開き）をリアルタイムで判定します。
- 「笑ったら負け」の睨めっこ遊びをデジタルで体験できます。
- COUの表情の変化や駄洒落でユーザーを笑わします（Rich Version）
- 難易度スライダーで判定のしきい値を調整できます。(Rich Version)

## ③アプリのデプロイURL
https://osorayama.github.io/jankenApp_richVersion/

## ④アプリのログイン用IDまたはPassword（ある場合）
- ログイン不要

## ⑤工夫した点・こだわった点
- CPUがランダムで笑う仕組みにし、シンプルでもゲーム性を実現
- MediaPipe FaceLandmarkerで顔のランドマーク（口・目・輪郭等）を検出
- ランドマークから口の開き具合を算出し、「笑ったかどうか」を自動判定
- 難易度スライダーで判定のしきい値（口の開き）を動的に変更可能
- MediaPipeのWebAssemblyモデル（face_landmarker.task）をローカルで利用


## ⑥難しかった点・次回トライしたいこと（又は機能）
- 表情検出の基準値取得が難しく、精度調整に苦労しました。
- 非同期処理のタイミング制御が複雑で、MediaPipeの処理順を理解するのに苦労しました。
- 次回はウインクや眉の動きなど、複数表情に対応したものを作りたいです。
- CPUキャラのアニメーションやデザインも強化したいです。
